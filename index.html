关于 Vibecraft

Vibecraft 是一个为 Claude Code 打造的 3D 可视化应用。

实时观察并管理你的 Claude 成员 - 现在支持六边形网格！

Vibecraft 会同步运行在本地机器上的 Claude Code 实例。任何文件或代码都不会发送到该网页服务器。

命令行指令 (Commands)
npx vibecraft启动服务器
npx vibecraft doctor诊断问题
npx vibecraft setup重新安装钩子
npx vibecraft uninstall移除钩子
故障排除 (Troubleshooting)

如果某个区域卡住，可能是 Claude Code 正在等待输入或处于未知状态。 请连接 tmux 会话查看详情：

tmux ls列出所有会话
tmux attach -t session连接到指定会话
语音输入 (Voice Input)

要启用语音输入，请将 Deepgram API key 添加到 .env 文件中：

DEEPGRAM_API_KEY=your_key_here
